# account_sync_privacy UI/UX RD

> 配对实现 RD：`docs/rd/modules/account_sync_privacy/account_sync_privacy.impl.md`
> 全局基线：`docs/rd/2026-06-02-rhythm-commercial-global-rd.md`
> 工作流状态：`modules_split`

## 1. 模块目标

建立账号、同步、隐私和数据控制的信任界面，让用户理解数据如何保存、同步、导出和删除。

## 2. 目标用户

需要换机恢复、跨设备同步、隐私确认或数据控制的用户。

## 3. 页面范围与导航入口

- 我的页账号摘要
- 账号与同步页
- 数据接入与权限页
- 隐私与数据页
- 导出数据对话框
- 删除账号/清空本地数据确认框

## 4. 核心用户路径

1. 用户从我的页进入账号或隐私入口。
2. 用户查看登录状态、同步状态和数据接入状态。
3. 用户发起同步、重试或绑定账号。
4. 用户查看隐私说明、导出或删除数据。

## 5. 状态矩阵

| 状态 | 设计要求 |
| --- | --- |
| ideal | 同步状态和隐私入口清晰 |
| loading | 同步中不可重复触发 |
| error | 同步失败显示原因和重试 |
| permission | 健康权限状态可解释 |
| partial data | 本地有数据但未同步时明确说明 |
| disabled | 未登录时不触发云同步 |
| success | 同步成功轻反馈 |
| locked | 跨设备深度同步可承接会员策略 |

## 6. 设计来源

核对 Pencil 我的页、账号同步、数据接入、隐私与数据、确认对话框。

## 7. 设计冻结卡

- 必须保持：信任优先、危险操作清楚、同步失败可恢复。
- 可工程化调整：同步摘要卡和隐私入口分组。
- 不可偏离：不得隐藏数据删除和导出入口。

## 8. 验收门槛

- 未登录不触发云同步。
- 同步失败可重试。
- 危险操作有二次确认。
- 隐私文案不含模糊承诺。
