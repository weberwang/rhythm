# membership_paywall UI/UX RD

> 配对实现 RD：`docs/rd/modules/membership_paywall/membership_paywall.impl.md`
> 全局基线：`docs/rd/2026-06-02-rhythm-commercial-global-rd.md`
> 工作流状态：`modules_split`

## 1. 模块目标

在不破坏激活和核心闭环的前提下，清晰表达“持续改善”的订阅价值，并承接高意图付费触点。

## 2. 目标用户

已经感知核心价值，想查看恢复计划详情、稳定度解释、长期历史或高级目标策略的用户。

## 3. 页面范围与导航入口

- 轻量付费墙
- 会员中心页
- 权益说明弹层
- 受限能力入口横幅
- 恢复购买与购买失败反馈

## 4. 核心用户路径

1. 用户在高意图节点点击高级能力。
2. 系统展示该能力如何帮助持续改善。
3. 用户选择试用、年付、月付或永久会员。
4. 购买成功后返回原能力。

## 5. 状态矩阵

| 状态 | 设计要求 |
| --- | --- |
| ideal | 年付主推但不焦虑营销 |
| loading | 购买中保持清晰反馈 |
| error | 购买失败可重试或关闭 |
| permission | 不涉及平台权限 |
| partial data | 权益读取失败时降级 |
| disabled | 不可购买时说明原因 |
| success | 返回原高意图能力 |
| locked | 解释价值，不只列功能 |

## 6. 设计来源

核对 Pencil 轻量付费墙、会员中心和会员相关弹层。付费墙文案必须继承商业 PRD。

## 7. 设计冻结卡

- 必须保持：免费层给结果、付费层给改善、高意图再拦截。
- 可工程化调整：价格卡布局和权益说明层级。
- 不可偏离：不得首开强弹付费墙。

## 8. 验收门槛

- 首次激活、目标设置、补录、今日页不被付费墙阻断。
- 受限能力能解释用户得到什么改善。
- 恢复购买入口明确。
- 购买失败不破坏当前页面。
