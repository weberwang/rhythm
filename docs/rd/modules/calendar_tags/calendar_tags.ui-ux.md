# calendar_tags UI/UX RD

> 配对实现 RD：`docs/rd/modules/calendar_tags/calendar_tags.impl.md`
> 全局基线：`docs/rd/2026-06-02-rhythm-commercial-global-rd.md`
> 工作流状态：`modules_split`

## 1. 模块目标

用月历热力图、单日详情和轻量原因标签帮助用户理解最近作息偏移和晚睡原因。

## 2. 目标用户

想看趋势、补原因、理解某天为什么晚睡的回访用户。

## 3. 页面范围与导航入口

- 日历页
- 月历热力图
- 单日详情弹层
- 原因标签选择弹层
- 自定义标签弹层

## 4. 核心用户路径

1. 用户进入日历页。
2. 用户看到本月热力图和状态摘要。
3. 用户点击某天查看详情。
4. 用户补一个原因标签或修正记录。
5. 标签结果进入今日和洞察。

## 5. 状态矩阵

| 状态 | 设计要求 |
| --- | --- |
| ideal | 热力图围绕目标偏移表达 |
| loading | 月份切换保持稳定布局 |
| error | 查询失败可重试 |
| permission | 未授权时仍展示手动记录入口 |
| partial data | 缺失日显示未记录 |
| disabled | 无目标时引导目标设置 |
| success | 标签保存轻反馈 |
| locked | 30 天外历史可承接付费 |

## 6. 设计来源

核对 Pencil 日历页、单日详情、标签弹层和补充弹层。热力图色阶必须继承商业 PRD 的偏移语义。

## 7. 设计冻结卡

- 必须保持：目标偏移色阶、单日解释、标签极轻输入。
- 可工程化调整：热力格尺寸和月份切换控件。
- 不可偏离：不得做成复杂医学图表或多维筛选面板。

## 8. 验收门槛

- 缺失数据不显示为失败。
- 标签输入默认不超过 8 个常用项。
- 单日详情解释来源和偏移。
- 高级历史入口不影响基础查看。
