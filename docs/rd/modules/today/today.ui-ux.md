# today UI/UX RD

> 产物类型：`module_uiux_rd`
> 模块：`today`
> 文档成熟度：`split_draft`
> 日期：`2026-06-08`

## 1. 模块目标与目标用户

`today` 是用户每日回访的主入口。  
它需要在疲劳、分心或赶时间的状态下，让用户快速看懂“昨晚怎样、今晚怎样、现在该做什么”。

## 2. 页面范围与导航入口

- 页面范围：
  - Today 顶层页
  - 快捷补录入口
  - 恢复建议摘要入口
  - 睡前模式进入入口
- 导航入口：
  - 底部导航 `Today`
  - onboarding 完成后的默认首落点
  - 深链或通知回访后的默认主页

## 3. 核心用户路径

1. 用户进入 Today，先看到昨晚结果与今晚行动优先级。
2. 若昨晚数据缺失或异常，用户快速进入补录/修正路径。
3. 若昨晚明显晚睡，用户优先看到恢复建议。
4. 用户可直接进入 Bedtime，或查看近 7 天趋势摘要。

## 4. 状态矩阵

| 状态 | 触发条件 | 承载位置 | 设计处理 |
| --- | --- | --- | --- |
| ideal | 数据完整且有今晚目标 | 首屏主内容区 | 主行动卡优先，结果与恢复次之 |
| loading | 记录或目标加载中 | 各主卡骨架位 | 保留版式，不闪烁 |
| empty | 无记录或首日使用 | 结果区/主卡区 | 引导补录或今晚建立第一步 |
| error | 同步失败或计算失败 | 页内状态位 | 可继续使用本地能力 |
| permission | 健康权限未授权 | 顶部说明区或主卡区 | 说明价值并给手动路径 |
| partial_data | 数据延迟或部分缺失 | 结果卡/趋势区 | 明确当前判断不完整 |
| disabled | 某入口暂不可用 | 快捷入口 | 说明原因，不干扰主 CTA |
| success | 昨晚达标或已完成补录 | 结果区 | 克制正反馈 |
| locked | 恢复详情锁定 | 恢复区 | 先展示价值，再露出升级入口 |

## 5. 结构语义

- `scroll_model`: `whole_page_scroll`
- `list_model`: `mixed`
- `overlay_model`: `bottom_action_area`
- `layout_model`: `linear`
- `sticky_model`: `none`
- `component_repeatability`: 主行动卡、结果摘要卡、恢复建议卡、快捷入口行、趋势摘要块

## 6. 模块级非页面组件设计骨架

| 组件 | 用途范围 | 状态/变体 | 复用边界 | 后续是否进入模块设计源冻结 |
| --- | --- | --- | --- | --- |
| 今晚行动卡 | 首屏主任务承载 | 默认、轻提醒、已完成 | Today 与 Bedtime 共享语义 | 是 |
| 昨晚结果卡 | 结果与偏移摘要 | 达标、轻偏移、明显偏移、缺失 | Today / Calendar 共享语义 | 是 |
| 恢复建议卡 | 晚睡后的下一步建议 | 免费摘要、锁定详情 | Today / Insights 共享语义 | 是 |
| 快捷补录入口行 | 补录/修正/查看详情 | 默认、禁用 | Today / Calendar | 是 |
| 7 天趋势摘要块 | 轻量趋势预告 | 正常、部分数据 | Today 专有 | 后续视复用决定 |

## 7. 设计源

- 共享冻结上游：
  - `docs/rd/global-design-guidelines.md`
  - `docs/rd/pencil-design-source-packet.md`
- 页面证据：
  - `docs/rd/pencil-exports/MCgNV.png`
- 设计约束：
  - 首屏第一重心必须是今晚行动
  - 图表、会员入口、历史摘要不得压过首屏主任务
  - CTA 必须保持安静邀请型
- 模块阶段默认不生成新预览

## 8. 设计冻结卡

- `freeze_status`: `reserved`
- `module_component_freeze`: `reserved`
- `high_fidelity_focus`: 今晚行动卡、昨晚结果卡与恢复建议卡的层级关系
- `immutable_constraints`:
  - 今晚行动高于结果摘要
  - 恢复建议在明显晚睡时前置
- `adjustable_items`:
  - 趋势摘要块的具体图形形式
  - 快捷入口的布局密度

## 9. 验收门

- UI/UX：
  - 首屏 3 秒内可读懂昨晚结果和今晚目标
  - 主 CTA 可预测发现
- 模块设计冻结：
  - 三张主卡的主次顺序稳定
  - 空态、权限态、部分数据态都有明确承载
- 代码交接：
  - Today 对 `sleep-data-core` 的依赖边界清晰
