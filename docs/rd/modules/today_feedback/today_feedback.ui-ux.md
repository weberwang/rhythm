# today_feedback UI/UX RD

> 配对实现 RD：`docs/rd/modules/today_feedback/today_feedback.impl.md`
> 全局基线：`docs/rd/2026-06-02-rhythm-commercial-global-rd.md`
> 工作流状态：`modules_split`

## 1. 模块目标

让用户每天打开 App 后 3 秒内读懂昨晚结果、今晚目标和下一步行动，是 Rhythm 的留存主入口。

## 2. 目标用户

完成激活后的每日回访用户，包括有完整数据、数据缺失、晚睡后需要恢复建议的用户。

## 3. 页面范围与导航入口

- 今日页
- 快捷记录入口
- 恢复建议摘要
- 近期趋势区块

## 4. 核心用户路径

1. 用户进入今日页。
2. 用户看到昨晚结果和今晚目标。
3. 用户选择进入睡前模式、补标签或手动修正。
4. 若明显晚睡，用户看到恢复建议摘要。

## 5. 状态矩阵

| 状态 | 设计要求 |
| --- | --- |
| ideal | 一个主摘要卡 + 一个主行动 |
| loading | 骨架或品牌等待，不闪烁 |
| error | 数据失败时提供重试和补录 |
| permission | 未授权时引导数据接入或手动记录 |
| partial data | 说明缺哪部分数据 |
| disabled | 无目标时引导目标设置 |
| success | 达标反馈克制正向 |
| locked | 恢复详情可作为高意图付费入口 |

## 6. 设计来源

核对 Pencil 今日页、恢复建议卡、快捷操作和趋势卡。若商业级 PRD 改变首屏文案，需要进入设计冻结。

## 7. 设计冻结卡

- 必须保持：首页 3 秒理解、晚睡后恢复优先、免费层可见核心结果。
- 可工程化调整：趋势图细节、快捷入口排列。
- 不可偏离：不得把今日页做成密集仪表盘。

## 8. 验收门槛

- 首屏能回答“昨晚怎样、今晚做什么”。
- 无数据、未授权、无目标都有明确下一步。
- 付费入口不阻断今日页阅读。
- CTA 不超过一个主焦点。
