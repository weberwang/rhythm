# widget_presence UI/UX RD

> 配对实现 RD：`docs/rd/modules/widget_presence/widget_presence.impl.md`
> 全局基线：`docs/rd/2026-06-02-rhythm-commercial-global-rd.md`
> 工作流状态：`modules_split`

## 1. 模块目标

通过小组件和桌面入口提升 Rhythm 在睡前时刻的可达性，同时控制隐私展示边界。

## 2. 目标用户

需要在桌面快速查看今晚目标、进入睡前模式或回到今日页的用户。

## 3. 页面范围与导航入口

- 小组件引导页
- 小组件与主题页
- 小组件预览
- 小组件刷新失败反馈
- 小组件点击入口

## 4. 核心用户路径

1. 用户在 onboarding 或我的页看到小组件价值。
2. 用户查看添加方式和预览。
3. 用户添加小组件。
4. 用户从小组件进入睡前模式或今日页。

## 5. 状态矩阵

| 状态 | 设计要求 |
| --- | --- |
| ideal | 展示今晚目标和入口价值 |
| loading | 刷新快照时轻提示 |
| error | 刷新失败可重试 |
| permission | 平台不支持时说明 |
| partial data | 无记录仍可展示目标 |
| disabled | 无目标时引导目标设置 |
| success | 添加或刷新成功轻反馈 |
| locked | 高级小组件可后续承接会员 |

## 6. 设计来源

核对 Pencil 小组件引导页、小组件与主题页和入口预览。

## 7. 设计冻结卡

- 必须保持：小组件服务睡前入口，不只是装饰主题。
- 可工程化调整：预览卡内容和刷新交互。
- 不可偏离：不得展示过细健康数据。

## 8. 验收门槛

- 无目标、无数据、未授权都有合理展示。
- 小组件只展示低敏摘要。
- 点击入口可回到今日或睡前。
- 添加失败不阻断主流程。
