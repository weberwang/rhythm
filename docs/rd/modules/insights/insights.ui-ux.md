# insights UI/UX RD

> 产物类型：`module_uiux_rd`
> 模块：`insights`
> 文档成熟度：`split_draft`
> 日期：`2026-06-08`

## 1. 模块目标与目标用户

`insights` 负责把零散行为转成“我最近怎么了、接下来怎么办、为什么值得升级”的理解。  
目标用户是已经开始形成回访习惯、希望理解趋势并接受恢复建议的用户。

## 2. 页面范围与导航入口

- 页面范围：
  - Insights 顶层页
  - 周报摘要区
  - 稳定度解释区
  - 原因分布区
  - 恢复计划区
  - 高级报告/付费承接区
- 导航入口：
  - 底部导航 `Insights`
  - Today 恢复建议详情入口
  - 周报提醒入口

## 3. 核心用户路径

1. 用户进入 Insights，先看到本周结果与一句行动结论。
2. 用户查看稳定度、原因分布与恢复计划摘要。
3. 用户对某个解释或计划有更强意图时，再进入高级详情或付费承接。

## 4. 状态矩阵

| 状态 | 触发条件 | 承载位置 | 设计处理 |
| --- | --- | --- | --- |
| ideal | 数据与周报完整 | 主内容区 | 一屏看懂本周表现与下一步 |
| loading | 报告生成中 | 骨架位 | 保持版式，避免空白 |
| empty | 数据不足 | 主内容区 | 解释为何暂无洞察，并引导继续记录 |
| error | 报告失败或恢复计划失败 | 页内状态位 | 说明并允许回退 |
| permission | 记录基础不足 | 页内说明区 | 不假装已有完整洞察 |
| partial_data | 本周部分缺失 | 摘要区/图表区 | 降级解释，标明不完整 |
| disabled | 某高级能力暂不可用 | 详情入口 | 说明原因 |
| success | 周报生成成功 | 摘要与详情入口 | 给出一句可行动结论 |
| locked | 高级报告或恢复详情锁定 | 相关区块 | 先展示价值，再露出升级理由 |

## 5. 结构语义

- `scroll_model`: `whole_page_scroll`
- `list_model`: `mixed`
- `overlay_model`: `modal_layer`
- `layout_model`: `linear`
- `sticky_model`: `none`
- `component_repeatability`: 周报摘要卡、稳定度解释块、原因分布块、恢复计划卡、高级报告锁定卡

## 6. 模块级非页面组件设计骨架

| 组件 | 用途范围 | 状态/变体 | 复用边界 | 后续是否进入模块设计源冻结 |
| --- | --- | --- | --- | --- |
| 周报摘要卡 | 本周概览与一句结论 | 正常、部分数据 | Insights 专有 | 是 |
| 稳定度解释块 | 解释最近节奏稳定程度 | 免费摘要、锁定详情 | Insights 专有 | 是 |
| 原因分布块 | 晚睡原因概览 | 正常、数据不足 | Insights 专有 | 是 |
| 恢复计划卡 | 给出恢复方向 | 免费摘要、锁定详情 | Insights / Today 共享语义 | 是 |
| 高级价值卡 | 月报/高级报告/升级入口 | 默认、锁定、试用态 | Insights / Profile 共享商业语义 | 是 |

## 7. 设计源

- 共享冻结上游：
  - `docs/rd/global-design-guidelines.md`
  - `docs/rd/pencil-design-source-packet.md`
- 页面证据：
  - `docs/rd/pencil-exports/OSwll.png`
- 设计约束：
  - 每个图表旁都必须有一句可行动结论
  - 不允许做成复杂医学仪表盘
  - 付费入口不能压过恢复与解释本身
- 模块阶段默认不生成新预览

## 8. 设计冻结卡

- `freeze_status`: `reserved`
- `module_component_freeze`: `reserved`
- `high_fidelity_focus`: 周报摘要、恢复计划卡、高级价值卡的主次关系
- `immutable_constraints`:
  - 先解释和帮助，再商业承接
  - 任何高级入口都不能破坏主闭环语义
- `adjustable_items`:
  - 图表/分布的具体视觉形态
  - 高级价值卡的露出方式

## 9. 验收门

- UI/UX：
  - 用户能看懂本周表现和下一步建议
  - 高级入口不会抢主任务
- 模块设计冻结：
  - 恢复、稳定度、商业入口层级稳定
- 代码交接：
  - 指标口径、恢复计划来源、锁定边界清晰

## 10. 开放问题

- 稳定度解释的免费/付费边界仍需产品商业侧最终冻结。
