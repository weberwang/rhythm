# 项目工作流文档目录

本目录用于存放需要长期保留的 Flutter 工作流产物，便于后续继续推进设计冻结、模块拆分、架构与实现。

- `intake/`：原始需求输入与改写前资料。
- `prd/`：已经成型的 PRD 文档。
- `rd/`：全局技术基线、设计设备预设等研发实施文档。
- `design/recommendations/`：设计方向候选图与评审用视觉材料。
- `workflow/`：工作流索引、整理说明等目录级管理文件。

根目录 [DESIGN.md](/E:/Projects/flutter/rhythm/DESIGN.md) 按工作流约定保留在项目根，不迁入 `docs/project/`。

运行态工作流记录位于 [workflow-record.md](/E:/Projects/flutter/rhythm/tmp/flutter-workflow-orchestrator/workflow-record.md)，用于当前流程状态追踪，不作为长期归档产物。
