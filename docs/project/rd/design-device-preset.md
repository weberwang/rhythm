# Rhythm 设计设备预设冻结记录

## 基本信息

- 冻结日期：2026-06-09
- 适用阶段：全局设计方向确认前置
- 平台：iPhone 首发基线
- 设计设备预设：`390 x 844 px`
- 语义说明：标准 iPhone 基线视口

## 选择理由

- 作为移动端首发基线，`390 x 844` 在信息密度、可读性和主流 iPhone 适配面之间更平衡。
- 相比 `375 x 667`，它更适合承载 Rhythm 当前需要的今日页信息层级、睡前模式主动作和洞察摘要。
- 相比 `430 x 932`，它不会过度放大大屏布局假设，更适合作为后续共享设计冻结的统一基准。

## 冻结约束

- 后续 Product Design brief、视觉方向推荐、`DESIGN.md`、结构化设计源和实现恢复，默认都以此视口为共享基线。
- 在用户未明确要求变更前，不再切换到其他主设计视口。
