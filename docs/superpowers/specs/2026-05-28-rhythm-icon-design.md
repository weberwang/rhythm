# Rhythm App Icon Design

## 目标

为 `Rhythm` 生成一张 `512x512` 的应用图标，服务于应用商店、启动图标导出和后续多尺寸适配。

## 已确认方向

- 主题意境：晨起新生
- 表现方式：插画氛围
- 最终方案：晨雾日升

## 视觉定义

- 主体意象：一轮刚越过地平线的晨日
- 前景结构：2 到 3 层柔和起伏的地平线或晨雾层
- 隐含语义：地平线轮廓同时承载“节律重新校准”的轻微波形感
- 画面气质：苏醒、轻盈、恢复、重新找回状态

## 风格约束

- 使用插画化表达，不走写实摄影路线
- 保持小尺寸识别，避免过细碎的装饰细节
- 不放置文字、字母和品牌首字母
- 不使用医疗十字、心电图等泛健康行业符号
- 不使用夜色、月亮、深蓝睡眠系主叙事

## 色彩方向

- 基础深绿：参考项目品牌色 `#2D5E3A`
- 浅色底：参考项目背景色 `#F5F3EE`
- 晨光辅助色：以柔和杏金、暖桃色作为高光
- 总体控制：暖晨光 + 植物感绿色，避免高饱和霓虹感

## 构图要求

- 画幅比例：`1:1`
- 输出尺寸：`512x512`
- 容器形式：适合 App 图标裁切的圆角方形构图
- 视觉重心：中上部晨日，下半部层叠雾带或地形
- 边缘处理：保留安全留白，避免主体过贴边影响系统裁切

## 交付物

- 第一版位图图标：`PNG`
- 建议保存到项目内，作为后续导出多平台图标的母版资产
